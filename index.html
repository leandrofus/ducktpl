Quick Start

Scaffold a full-stack project in seconds:

# 1. Create a project
npx create-duck myapp -y --web preact --rls singleTenant --with eventbus,ws

# 2. Add an interactive resource with visual cards
cd myapp
npx ducktpl add profiles 'name:string!' 'bio:text' 'avatar_url:string' 'status:string!:enum(online,away)' --ui cards

# 3. Add custom RPC action
npx ducktpl addAction profiles boost

# 4. Subscribe to domain events
npx ducktpl on profiles.create notifyAdmin --preset email

# 5. Run development server (Go backend + Vite hot-reload)
make dev

Declarative YAML Blueprint

Define your entire multi-resource architecture in a single blueprint file:

# app.yaml
resources:
  profiles:
    ui: cards
    fields:
      - display_name:string!
      - avatar_url:string
      - bio:text
  messages:
    ui: chat
    fields:
      - profile:ref:profiles!
      - content:text!

pipelines:
  - on: messages.create
    name: onNewMessage
    preset: log
npx ducktpl apply app.yaml
